# Система учёта внутриофисных расходов (АИС «УВР»)

Проект разработан в рамках учебной практики. Система предназначена для автоматизации учёта мелких покупок, совершаемых сотрудниками фирмы для служебных нужд.

## Основные возможности
- Ведение справочников отделов, сотрудников, видов расходов и лимитов.
- Регистрация покупок с прикреплением электронных копий чеков.
- Автоматический контроль непревышения месячных лимитов.
- Формирование отчётов по отделам, видам расходов и периодам.

## Стек технологий (проектируемый)
- Серверная ОС: Linux (Astra Linux / Ubuntu)
- СУБД: PostgreSQL
- Сервер приложений: Python (Django) / Java (Spring Boot)
- Клиент: веб-браузер

## Статус проекта
